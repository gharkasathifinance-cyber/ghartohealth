Air ambulance tracking and billing

Set the rate card once. Start a mission for a booking, press Take-off and Landed, and the bill is built from the flight log.

Rate card

Hourly rate 0 means not set yet, so bills show only the extra charges. Medical team, ground ambulance and similar charges still come from the Air Ambulance Charges page.

Operators: once you list operators of a type on the Air Operators & Charges page, each operator's own rates and base airport are used and this rate card is used only for a type that has no operator listed.
