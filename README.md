# Ghar to Health - Full Stack Booking Platform

## Included
- Professional responsive frontend
- Express backend
- Clickable service cards
- Service detail popup/modal
- Service-specific starting prices
- Booking form with date/time/address
- UPI payment option placeholder/ready flow
- Pay After Service option
- Booking ID generation
- Admin booking dashboard
- Booking status and payment status updates
- WhatsApp booking handoff

## Run locally
1. Install Node.js
2. Extract this ZIP
3. Open terminal in the project folder
4. Run: npm install
5. Run: npm start
6. Open: http://localhost:3000
